# Chat / Design Coverage Matrix

This package is explicitly based on the accessible SolomonPrime/TED design material and the current controller host + worker-node build session.

Included concepts:

- local-first networking: direct Ethernet > wired LAN > Wi-Fi > Tailscale
- authenticated dynamic mesh discovery and signed heartbeats
- hardware-aware deterministic scheduling with bounded LLM advice
- controller host dual-GPU local inference and worker-node simulation-worker role
- Open WebUI front end and Tailscale remote access
- tiered short/long-term memory, provenance, deduplication, consolidation, archival
- read-only Storage Steward first project
- specialist agent contracts and critic/reviewer pattern
- approval and hash-chained audit foundations
- bounded cloud escalation with no-overage local quotas
- cloud teacher-candidate capture without automatic model promotion
- Goal Engine
- bounded distributed Job Executor
- Experiment Ledger / reproducibility hashes
- safe self-improvement principle: benchmark and approve before promotion
